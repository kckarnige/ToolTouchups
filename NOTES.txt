=====// Armor & Tools //=====

Leather : Wood/Stone -> Chain : Copper/Gold -> Iron : Iron/Bronze -> Steel : Steel/Diamond -> Netherite : Netherite/End

Less Durability -> Different tools have different advantages (gold tools have a use now!)

===============

Upgrades:

Iron -> Bronze
Gold -> Diamond
Steel -> Netherite

Raw copper tools -> Smelt copper on a campfire -> Use copper to make a furnace (possible under the right circumstances in real-life)

Steel requires blast furnace which now requires Bronze

===============

=====//   Crafting   //=====

Killing sheep drops string instead of wool ( ! ! MAKE SURE WOOL CAN TURN BACK INTO STRING ! ! )

Beds now take longer to craft

	Cloth can either be crafted from string, or have a chance to be dropped by zombies

	A pillow can be crafted with feathers, cloth, and string. Wool can be used as a replacement for feathers to make a "Soft Pillow"

	Beds only skip the night if the player crafts it using a "Soft Pillow", crafting a "Comfy Bed"

	Standard beds only set the player spawn point, while "comfy" beds work like vanilla beds.
